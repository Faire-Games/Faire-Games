# Pipes sound

`turn.wav` is an original synthesized mechanical click made for Day Games: damped
480 Hz and 960 Hz tones plus a short noise transient, without sampled material.
Copyright The Daybrite Project, Apache-2.0. 16-bit PCM WAV, mono, 44.1 kHz.
Shared gamekit cues provide locking, menus, restart, and completion feedback.
